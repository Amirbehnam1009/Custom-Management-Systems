# سامانه مدیریت قرارداد و کوتاژ

برنامه وب برای جایگزینی ثبت دستی قرارداد و اظهار گمرکی (کوتاژ) در فایل‌های اکسل دو شرکت:

- شرکت تولیدی معدنی آتشکده خراسان
- شرکت گچ خراسان

کارکنان می‌توانند قرارداد و کوتاژ را از طریق سایت ثبت، ویرایش، جستجو و گزارش‌گیری کنند. اکسل فقط برای ورود سوابق تاریخی و خروجی گزارش استفاده می‌شود.

## امکانات تکمیل‌شده

- داشبورد با آمار واقعی پایگاه داده و فیلتر شرکت، تاریخ، مشتری، محصول و محل تحویل
- ثبت و ویرایش قرارداد
- ثبت چند کوتاژ برای هر قرارداد
- محاسبه خودکار مانده تناژ: مقدار قرارداد منهای کوتاژ نهایی
- کوتاژ ابطال‌شده در تناژ معتبر محاسبه نمی‌شود
- کوتاژ در انتظار از کوتاژ نهایی جدا نمایش داده می‌شود
- هشدار شماره قرارداد تکراری در یک شرکت
- جلوگیری از تناژ منفی مگر با مجوز تنظیم
- جستجو، فیلتر و خروجی اکسل با اصطلاحات فارسی فایل‌های اصلی
- ورود فایل اکسل تاریخی
- ورود، نقش مدیر/کارشناس، تاریخچه تغییرات و پشتیبان پایگاه داده

## پیش‌نیاز

- Python 3.11 یا جدیدتر
- Windows 10/11 با VS Code (یا هر سیستم‌عامل دیگر)

## نصب در VS Code روی ویندوز

1. پوشه پروژه را در VS Code باز کنید.
2. ترمینال را باز کنید: Terminal > New Terminal
3. محیط مجازی بسازید:

```bash
python -m venv .venv
```

4. محیط مجازی را فعال کنید:

```bash
.venv\Scripts\activate
```

5. وابستگی‌ها را نصب کنید:

```bash
pip install -r requirements.txt
```

6. برنامه را اجرا کنید:

```bash
python app.py
```

7. مرورگر را باز کنید و به آدرس زیر بروید:

```text
http://127.0.0.1:5000
```

## حساب‌های پیش‌فرض

- مدیر: `admin` / `admin123`
- کارشناس: `employee` / `employee123`

پس از ورود، رمزها را تغییر دهید.

## ساختار پروژه

```text
app.py

templates/
static/

```

پایگاه داده SQLite در `instance/kotaj.db` ساخته می‌شود. ساختار جداول برای مهاجرت بعدی به PostgreSQL آماده است.

از صفحه تنظیمات می‌توان فایل اکسل جدید نیز وارد کرد.

## قوانین محاسبه

مانده تناژ = مقدار قرارداد - مجموع تناژ کوتاژهای با وضعیت «کوتاژ نهایی شد»

- وضعیت «کوتاژ ابطال شد» در مانده لحاظ نمی‌شود.
- وضعیت «در انتظار تکمیل» جداگانه نمایش داده می‌شود و از مانده کسر نمی‌شود.

## نکات استخراج‌شده از فایل‌های اکسل

- هر قرارداد می‌تواند چند کوتاژ داشته باشد؛ کوتاژها در سامانه رکورد جدا هستند، نه متن جداشده با /.
- کوتاژ ابطال‌شده (مانند قرارداد `1405031999` شرکت گچ خراسان) از مانده تناژ کسر نمی‌شود.
- برخی شماره کوتاژها فقط در جدول اصلی آمده‌اند و جزئیات تناژ ندارند؛ این موارد علامت «نیاز به بررسی» می‌گیرند.
- در فایل آتشکده، قرارداد `140574770` در جدول اصلی با کوتاژهای `5935469/5952433` آمده، اما بلوک جزئیات همان کوتاژها را زیر شماره `1405042343` نشان می‌دهد. هر دو برای بررسی دستی علامت خورده‌اند و ادغام نشده‌اند.
- اختلاف‌های یک‌تنی یا مانده‌های دستی اکسل (مثل یادداشت «یک تن گمرک») در محاسبه سامانه از روی کوتاژهای واقعی اعمال می‌شود و در صورت تفاوت با ستون مانده اکسل، قرارداد علامت می‌خورد.

## محدودیت‌ها

- تاریخ‌ها به همان صورت شمسی متنی فایل اکسل ذخیره می‌شوند و تقویم شمسی تعاملی جداگانه اضافه نشده است.
- برخی کوتاژهای فایل اصلی ارتباط مبهم با قرارداد دارند؛ این موارد با برچسب «نیاز به بررسی» مشخص می‌شوند.
- SQLite برای استقرار تک‌سرور مناسب است. برای چند کاربر همزمان روی شبکه، برنامه را روی یک سرور مرکزی اجرا کنید یا بعداً به PostgreSQL مهاجرت دهید.
